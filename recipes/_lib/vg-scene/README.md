# vg-scene

Shared building blocks for VideoGenome scene recipes (MIT, part of VideoGenome):
the frame loop, easing and springs, measured text fitting with balanced wraps,
contrast-safe colour choice, number formatting, grain, vignette, dot grids and
beat planning. Import it from a recipe as `../../_lib/vg-scene/vg-scene.js`, or
from any captured page as `/_lib/vg-scene/vg-scene.js`.
